Three-layer detection

Pattern rules screen first, an ML classifier scores the rest, and an LLM judge confirms — fast filters first, deep reasoning when it matters.

Every modality covered

Text, HTML, images (multi-pass OCR catches white-on-white), PDFs (hidden layers + metadata) and audio via transcription.

Onchain registry

Attack fingerprints publish to a shared registry on Base Sepolia. No central operator. Immutable. Auditable forever.

Network-wide immunity

Every agent polls the registry and caches signatures locally. One detection means every node in the network is protected within seconds.
